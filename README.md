# Nのうんどう瓶

自分専用の運動モチベーションアプリです。
運動を記録すると、その分が「瓶」にたまっていきます。主人公はおだんごヘアの女の子「N」です。

- スマホのブラウザで動く Web アプリ（HTML / CSS / JavaScript）
- ホーム画面にアイコンを置いて、アプリのように使える（PWA）
- データはスマホの中（localStorage）にだけ保存。ログインなし

## いまできること

### 1. 運動の記録
- 種目をタップ → 時間ボタンを押すだけで記録
- 記録したあとに「−5分」「+5分」「+10分」で時間を調整できる
- まちがえたら：記録した画面の「取り消す」、閉じたあと数秒出る「取り消す」、または「今週の記録」の「直す」から時間を変えたり消したりできる（消したあとも「もとに戻す」で戻せる）
- 消費カロリーと、燃えた脂肪の量（g）を表示
- 体重は最初に1回だけ入力（画面には表示しない。右上の歯車から変更できる）

| 種目 | 時間ボタン | 瓶の色 |
| --- | --- | --- |
| ピラティス | 10分 / 50分 | 琥珀色 |
| 筋トレ | 15分 / 30分 | コーラルピンク |
| ウォーキング | 20分 | ミントグリーン |
| ツイストステッパー | 20分 | ラベンダー |
| ストレッチ | 5分 / 10分 | 水色 |

### 2. 瓶（週のゲージ）
- 毎週、9種類の瓶（まんまる・ハート・星・宝石・しずく など）からランダムに1つ選ばれる。となりの週とそっくりな瓶にはならない
- 運動した分が、種目の色の層になって瓶にたまる
- 週250分で満タン。毎週月曜に新しい瓶になる（数字は画面に出さない）
- 1日のノルマ（35分）をクリアすると N がよろこぶ
- 満タンになった週の瓶は「瓶の棚」に並ぶ

### 3. 食事の記録（下のタブ「ごはん」）
- 朝・昼・夜ごとに「腹八分目だった？」を「腹八分目」「食べすぎた」でワンタップ
- お米は「少なめ」「いつも通り」「おかわり」をタップ（グラムは入れない）
- おやつ・つまみ食いは1日1回「しなかった」「しちゃった」。しなかった日には週のカレンダーに花まるがつく
- 同じボタンをもう一度押すと取り消せる。「‹ ›」やカレンダーで前の日も入力・修正できる

## スマホで使えるようにする手順（GitHub Pages で公開）

パソコンがなくても、スマホのブラウザで GitHub を開けばできます。

### ステップ1：リポジトリを「公開（Public）」にする
無料の GitHub では、非公開のリポジトリは GitHub Pages で公開できません。

1. ブラウザで `https://github.com/nono6767/insta-auto-post` を開く
2. 「Settings」（設定）を開く（スマホでは画面上部の「…」メニューの中にあることがあります）
3. いちばん下の「Danger Zone」→「Change visibility」→「Change to public」

> 公開されるのはアプリのプログラムだけです。運動の記録や体重はスマホの中にしか保存されないので、インターネットには出ません。

### ステップ2：GitHub Pages をオンにする
1. 同じ「Settings」の左メニュー（スマホでは一覧の中）から「Pages」を開く
2. 「Build and deployment」の「Source」を「Deploy from a branch」にする
3. 「Branch」で `claude/instagram-caption-generator-i7qxzs` を選び、フォルダは `/ (root)` のまま「Save」
4. 1〜2分待つと、ページの上に公開URLが出ます：
   `https://nono6767.github.io/insta-auto-post/`

### ステップ3：ホーム画面に追加する
- **iPhone（Safari）**：公開URLを開く → 下の共有ボタン（□に↑）→「ホーム画面に追加」
- **Android（Chrome）**：公開URLを開く → 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」

ホーム画面の N のアイコンから開くと、アプリのように全画面で使えます。

## データについて（大事）
- 記録はそのスマホのそのブラウザの中にだけあります。機種変更や、ブラウザの「履歴とWebサイトデータを消去」をすると消えてしまいます。
- iPhone では、ホーム画面に追加したアプリとして使うのがおすすめです（Safari のタブで開くだけだと、しばらく使わないとデータが消されることがあります）。

## ファイルの地図

| ファイル | 中身 |

| `index.html` | 画面の骨組み |
| `css/style.css` | 色や形などの見た目 |

### よく変えそうな設定
`js/app.js` のいちばん上にまとめてあります。

- `SPORTS`：種目の名前・色・時間ボタン・運動の強さ（MET）
- `WEEK_GOAL_MIN`：瓶が満タンになる分数（250）
- `DAILY_QUOTA_MIN`：毎日のノルマ（35）

消費カロリーは「MET × 体重(kg) × 時間(時間) × 1.05」、脂肪の量は「消費カロリー ÷ 7.2」で計算しています（どちらも目安です）。
