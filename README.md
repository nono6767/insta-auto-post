# Nのうんどう瓶

自分専用の運動モチベーションアプリです。
運動を記録すると、その分が「瓶」にたまっていきます。主人公はおだんごヘアの女の子「N」です。

- スマホのブラウザで動く Web アプリ（HTML / CSS / JavaScript）
- ホーム画面にアイコンを置いて、アプリのように使える（PWA）
- データはスマホの中（localStorage）にだけ保存。ログインなし

## いまできること

### 1. 運動の記録
- 種目をタップ → 時間ボタンを押すだけで記録
- 記録したあとに「−5分」「+5分」「+10分」で時間を調整できる
- まちがえたら：記録した画面の「取り消す」、閉じたあと数秒出る「取り消す」、または「最近の記録」（7日前まで）の「直す」から時間を変えたり消したりできる（消したあとも「もとに戻す」で戻せる）
- 入れ忘れた日も、運動を選んだ画面の「今日／きのう／おととい／ほかの日」で、7日前まであとから記録できる（その日の小瓶に入る。今日のノルマやカロリーには入らない）
- 消費カロリーと、燃えた脂肪の量（g）を表示
- 体重は最初に1回だけ入力（画面には表示しない。右上の歯車から変更できる）

| 種目 | 時間ボタン | 瓶の色 |
| --- | --- | --- |
| ピラティス | 10分 / 50分 | 琥珀色 |
| 筋トレ | 15分 / 30分 | コーラルピンク |
| ウォーキング | 20分 | ミントグリーン |
| ツイストステッパー | 20分 | ラベンダー |
| ストレッチ | 5分 / 10分 | 水色 |

### 2. 小瓶と大瓶（毎日の小瓶 → 合成して大瓶に進化）
- 運動を記録した日に、その日の **小瓶** が1つできる（同じ日に何回記録しても1つ）。中身はその日の分数と種目ごとの色の層で、36分くらいで満タンに見える。形は瓶のイラスト9種類を日付ごとにくり返す
  - 中身は淡いパステルの半透明で、層の境目はやわらかくぼかす。ガラスの線とツヤ（`bottles/〇〇-shine.webp`）が中身の上に見える
  - 36分をこえた日も、そのあとの運動の色が足される（全部の運動の分数の割合で層を分け直す）。どんなに短い運動も細い層として必ず見える。満タンをこえた日は瓶のまわりがキラキラする
- ホームの瓶は「今日の小瓶」。下に「大瓶まであと○分」
- 下のタブ「瓶の棚」の **小瓶の棚** に、まだ合成していない小瓶が日付の札つきで並ぶ（4段×5つ。週でリセットしない）。小瓶の本数・合計分数・「大瓶まであと○分」を表示
- 小瓶の合計が250分をこえると「合成する」ボタンが光る（その瞬間に N がお知らせ）。押すと、古い小瓶から順に250分ぶんがまとまって **大瓶** に進化する（キラキラの演出つき）
- 250分をこえた分は、**おまけの小瓶**（金色の札）として小瓶の棚に残り、次の合成に使う
- 大瓶に入っている記録を消したり、大瓶に使った分より少なく直したりすると、「大瓶を小瓶に戻す／大瓶はそのまま／やめる」を聞いてくる（勝手には戻さない）。小瓶に戻すと、その大瓶はなくなって中の運動は小瓶の棚に戻る（チャームもはずれる）
- **大瓶の棚** は金のふちとローズのベルベットの「ごほうびショーケース」。ガラスの棚に3つずつ×3段（9本）、進化した日の順に左上から並び、札は進化した日付。9本をこえたら「‹ ›」で次のページへ。大瓶は小瓶の2倍より少し大きく、うしろがふんわり光り、ガラスにときどき光がすーっと流れる（小瓶のキラキラは控えめ）
  - 大瓶はチャームなしの瓶のイラスト（`big/`、9種類：まる・ハート・星・電球形・かぼちゃ形・すらっと・ダイヤ・ドーム形・しずく）。中身はパステルの層で、体の8割まで
- **チャーム**：大瓶に進化したら、74種類のチャーム（`charms/`）から **1本に3個まで** 選んでつけられる（最初から全部選べる。押した順に①②③、もう一度押すとはずれる・「ぜんぶはずす」もOK）
  - チャームは種類ごとにつけ方がちがう：**下げる**（ペンダント類。首に巻いたシャンパンゴールドの細いチェーンから、短いチェーンで下がってゆれる。1個＝まん中、2個＝右と左、3個＝右・左・まん中）／**首に巻く**（リボン・ネックレス）／**ふた**（宝石のふた。もとのコルクやふたはかくれる）／**台**（馬車の車輪）
  - 大瓶の棚で大瓶をタップすると、あとからチャームを付け替えられる
- **シェイク**：夜、ホームの小瓶の下の「今日はおしまい」を押すと、今日の小瓶をシェイクできる。小瓶をタップすると（「iPhoneを振ってシェイク」で動きの許可をすると、振ってもOK）シャカシャカ揺れて、中身がまざって **その日の色** になる
  - その日の色は、種目ごとの分数の割合で色を混ぜて決まる。近い色どうしはあいだの色、反対の色どうしは落ち着いた色に。たくさん運動した日ほど色がこく、短い日は淡くなる。いちばん近い色の名前（パステルの50色。`js/colors.js`）がつく
  - 押し忘れた日は、次の日に開いたとき1回だけ「きのうの小瓶、シェイクしよう」と出る。それより前の日も、小瓶の棚で小瓶をタップすればシェイクできる
  - シェイクしたあとに運動を足したり直したりすると、またグラデーションに戻って、もう一度シェイクできる
  - シェイクした小瓶は、札がその日の色になって色の名前が出る。タップすると、もとの層と種目ごとの分数が見られる
  - 合成した大瓶の中身は、その日ごとの色の層を古い順に重ねる（シェイクしていない日も、その日の色を計算して使う）
- **色図鑑**（瓶の棚の3つめ）：シェイクして出た色が集まる。まだ出ていない色は見えず、「○色 / 50色」だけ出る。はじめて出た色のときは「新しい色！」
- 前のしくみ（週の瓶）で満タンになった週は、そのまま大瓶として残っている（札は、その週に250分に届いた日）。満タンにならなかった週の運動は、小瓶になっている
- 毎日のノルマ（約35分）をクリアすると N がよろこぶ
- 花まる（おやつ・つまみ食いをしなかった日）は、その日の小瓶と、その日を含む大瓶にお花として入る

### コインとチャームのガチャ
- 右上（左がわ）の **コイン** をタップすると、ガチャの画面が開く。無料ガチャが残っている日は、ピンクの点がつく
- **コインのもらい方**：運動のノルマ達成 +1（1日1回）／食事の記録 +1（1日1回）／生理の記録 +1（ボーナス）／大瓶に進化 +3。もらうと「+1」がふわっと出る
- **ガチャ**：毎日1回無料。1コインで1回、10コインで11連（ピックアップのチャームが1個以上確定。結果はまとめて表示）
- **ピックアップ**：開催中のシリーズは50%の確率で出る。終わったシリーズは、ふつうのガチャにひくい確率で入る
- **シリーズ**：ベーシックライン（最初から全部持っている）／ワンコシリーズ・バレエシリーズ（ガチャ限定。最初は持っていない）。大瓶の「チャームを付け替える」には、持っているチャームだけが出る
- **かけら**：持っているチャームがかぶると、かけら+1。10個で、まだ持っていない好きなチャームと交換できる
- 数（もらえるコイン・ガチャの値段・確率・かけらの数・ピックアップの期間）は、`js/gacha.js` のいちばん上にまとめてある。シリーズ分けは `js/bigbottles.js` のチャームの `series`

### 3. 食事の記録（下のタブ「ごはん」）
- 朝・昼・夜ごとに「腹八分目だった？」を「腹八分目」「食べすぎた」でワンタップ
- お米は「少なめ」「いつも通り」「おかわり」をタップ（グラムは入れない）
- おやつ・つまみ食いは1日1回「しなかった」「しちゃった」。しなかった日には週のカレンダーに花まるがつく
- 花まるの日は、その日の小瓶にお花が浮かぶ。合成した大瓶には、ふくまれる花まるの日の数だけお花が入る（最大7個）
- 同じボタンをもう一度押すと取り消せる。「‹ ›」やカレンダーで前の日も入力・修正できる

### 4. 毎日の体調・生理（下のタブ「からだ」）
- 体調と気分を、それぞれ「Good」「Bad」でワンタップ（ノルマにはしない。もう一度押すと取り消し）
- 生理は「今日、生理がきた」「今日で終わった」をワンタップ。「‹」で前の日に戻れば、その日で記録できる
- 「これまでの生理」の「直す」から、日付の修正や記録の削除ができる
- 週のカレンダーに、体調・気分の点（緑＝Good、紫＝Bad）と生理のしずくが出る
- 前回の生理の開始日から、いつもの間隔（記録が少ないうちは28日）より7日以上空くと、ホームのNとからだタブでさりげなくお知らせ
- 生理中は、Nが「無理しないでね」と声をかける

### 5. 服チェック（下のタブ「服」）
- 「＋ 服を登録する」でお気に入りの服を名前で登録（「直す」で名前の変更・削除）
- 「写真を撮る」で、カメラかアルバムから写真を選ぶ。写真は長い辺800pxまで小さくして、スマホの中（IndexedDB）にだけ保存（iPhone は JPEG で1枚約40〜50KB、WebP で保存できるスマホは約20KB）
- 服タブのいちばん下に、写真が使っている容量（枚数・合計）が出る
- 前の版（長い辺1200px）で撮った写真は、アプリを開いたときに自動で小さくし直す
- 写真が2枚以上になると「見くらべる」で前回と今回を並べて見られる（日付を選んで別の回ともくらべられる）
- 毎月1日にアプリを開くと、Nが「今月の服チェックの日だよ！」とお知らせ（1回だけ）。1日に開かなかった月も、ホームのNがさりげなく教えてくれる
- 今月まだ写真を撮っていない服があると「あと○着」と出て、全部撮るとチェック完了

## スマホで使えるようにする手順（GitHub Pages で公開）

パソコンがなくても、スマホのブラウザで GitHub を開けばできます。

### ステップ1：リポジトリを「公開（Public）」にする
無料の GitHub では、非公開のリポジトリは GitHub Pages で公開できません。

1. ブラウザで `https://github.com/nono6767/insta-auto-post` を開く
2. 「Settings」（設定）を開く（スマホでは画面上部の「…」メニューの中にあることがあります）
3. いちばん下の「Danger Zone」→「Change visibility」→「Change to public」

> 公開されるのはアプリのプログラムだけです。運動の記録や体重はスマホの中にしか保存されないので、インターネットには出ません。

### ステップ2：GitHub Pages をオンにする
1. 同じ「Settings」の左メニュー（スマホでは一覧の中）から「Pages」を開く
2. 「Build and deployment」の「Source」を「Deploy from a branch」にする
3. 「Branch」で `claude/instagram-caption-generator-i7qxzs` を選び、フォルダは `/ (root)` のまま「Save」
4. 1〜2分待つと、ページの上に公開URLが出ます：
   `https://nono6767.github.io/insta-auto-post/`

### ステップ3：ホーム画面に追加する
- **iPhone（Safari）**：公開URLを開く → 下の共有ボタン（□に↑）→「ホーム画面に追加」
- **Android（Chrome）**：公開URLを開く → 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」

ホーム画面の N のアイコンから開くと、アプリのように全画面で使えます。

## 最新版になっているか確かめる
- 右上の歯車を押すと、いちばん下に「アプリの版」が出ます。
- 新しい版を公開すると、アプリを開いたとき（または戻ってきたとき）に自動で1回読み込み直して最新になります。
- 公開してからスマホに届くまで、数分〜10分ほどかかることがあります。

### 貯金瓶（下のタブ「貯金」）
- 毎週の金額・目標金額・期限は、右上の歯車 →「貯金瓶の設定」で自分で入力する（プログラムには書いていない）
- 「今週の分を入れた」を押すと、琥珀色のコインが1枚まんまるの瓶に入る。1週間（月〜日）に1回まで。まちがえたら「今週の分を取り消す」
- 入れ忘れた週があっても、次の週の金額は増えない。「未入金」「遅れ」などの表示は出さない
- 「追加で入れる」で好きな金額を入れられる（回数の制限なし）。追加の分はキラッとした特別なコインになる
- 瓶をタップすると、中のコインがポンポンッと跳ねて、瓶がぷるんと揺れる（「動きを減らす」設定のスマホでは動かない）
- 表示するのは「目標まであと○回」だけ。残りの金額 ÷ 毎週の金額（切り上げ）で計算するので、追加で入れるとその分へる
- 「入れた記録」から、どの回も取り消せる（取り消したあとも「もとに戻す」で戻せる）
- 貯金のデータも記録と同じ `n-app-data` に入るので、バックアップファイルにいっしょに入る

## バックアップ（右上の歯車 → 設定）
- **バックアップを保存**：運動・ごはん・からだ・服・貯金の記録と服の写真を、1つのファイル（`n-app-backup-日付.json`）にまとめる。iPhone では共有シートが開くので「"ファイル"に保存」などを選ぶ
- **バックアップから戻す**：保存したファイルを選ぶと、中身（運動○件・写真○枚など）を確認してから記録を元に戻す。今スマホにある記録はファイルの中身に置きかわる
- 機種変更したときは、最初の画面の「機種変更した人：バックアップから戻す」から戻せる
- 最後のバックアップ（まだなら使い始めた日）から2週間たつと、ホームの N がやさしくお知らせして、歯車に小さな点がつく

### 保存名について
このアプリがスマホに保存するものは、すべて名前が `n-app-` で始まります（同じ `nono6767.github.io` で公開するほかのアプリとまざらないように）。

| 保存するもの | 名前 |
| --- | --- |
| 記録（localStorage） | `n-app-data` |
| 服の写真（IndexedDB） | `n-app-photos` |
| オフライン用のファイル（キャッシュ） | `n-app-cache-v番号` |
| バックアップファイル | `n-app-backup-日付.json` |

前の版の保存名（`n-undou-bin…`）で記録していた場合は、開いたときに自動で新しい名前へ引っ越します。

## 通信量について
- 画像（N・瓶・棚の背景・アイコン）は、一度読み込んだらスマホに保存して、次からは通信しない。アプリが新しい版になっても、画像はダウンロードし直さない
- プログラムも版ごとにスマホに保存して、そこから表示する。新しい版が出たときだけ、その分をダウンロードする
- アプリを開くたびの通信は、新しい版があるかの確認（数KB）だけ。通信がなくても開ける
- 直す人へ：プログラムを直したら `sw.js` の `CODE_VERSION` を、画像を変えたら `IMAGE_VERSION` を1つ上げる

## データについて（大事）
- 記録はそのスマホのそのブラウザの中にだけあります。機種変更や、ブラウザの「履歴とWebサイトデータを消去」をすると消えてしまいます。
- 服チェックの写真もスマホの中にだけあります（アプリを消すと写真も消えます）。
- iPhone では、ホーム画面から開いたアプリと、Safari で開いたページは、記録が別々になります。いつも同じほうから開いてください。
- iPhone では、ホーム画面に追加したアプリとして使うのがおすすめです（Safari のタブで開くだけだと、しばらく使わないとデータが消されることがあります）。

### よく変えそうな設定
`js/app.js` のいちばん上にまとめてあります。

- `SPORTS`：種目の名前・色・時間ボタン・運動の強さ（MET）
- `WEEK_GOAL_MIN`：瓶が満タンになる分数（250）
- `DAILY_QUOTA_MIN`：毎日のノルマ（35）

消費カロリーは「MET × 体重(kg) × 時間(時間) × 1.05」、脂肪の量は「消費カロリー ÷ 7.2」で計算しています（どちらも目安です）。
